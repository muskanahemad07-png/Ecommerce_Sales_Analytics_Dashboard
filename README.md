This repository contains the source files, datasets, and visual models required to build an end-to-end e-commerce sales report. It transforms raw transaction and order records into actionable business intelligence, helping store owners and data analysts track profitability, customer behavior, and regional growth.

Key Features

• Sales & Revenue Tracking: Monitor total sales, net revenue, and Average Order Value (AOV) at a glance.
• Category & Product Analysis: View performance breakdowns across various product categories and identify top-selling items.
• Customer Insights: Identify and track top customers who generate the highest revenue.
• Geographical Insights: Analyze sales distribution and regional performance across different territories.
• Payment & Transaction Insights: Breakdown transaction methods to see which payment modes drive the most revenue.
• Dynamic Filtering: Interact with the data using native slicers for months and product categories to filter the entire report seamlessly.

Tech Stack & Tools

• Data Processing / Modeling: Power Query, DAX / Excel 
• Visualization Tool: Power BI / Excel / 
• Data Sources: Structured CSV / Relational Order & Order-Details datasets
